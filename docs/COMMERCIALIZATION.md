# Luma Bar 商业化路径（对标 Surge Mac）

> 落地操作手册见 [GO_TO_MARKET.md](./GO_TO_MARKET.md)。

> 原则：**功能不砍、不上架凑合过审；官网直销 + 买断授权 + 维护更新订阅。**  
> 对标对象：[Surge Mac](https://nssurge.com)（直销、试用、设备档位、永久可用 + 年度维护更新）。

---

## 1. 为什么学 Surge，而不是硬上 Mac App Store

| Surge 的做法 | Luma Bar 对应 |
|---|---|
| 因技术限制**不上 Mac App Store**，官网下载 | 辅助功能 / 跨 App 监测 / 系统控制等同理，**全功能只走官网** |
| 卖的是「专业工具能力」不是皮肤 | 卖「并行 AI 工作流中枢」：完成提醒、划词、Agent |
| 买断使用权 + 维护更新订阅 | 同样：**永久能用你买到的版本；要持续大更新再续维护期** |
| 14 天全功能试用 | 14 天全功能试用（到期回 Free 基础能力或锁定 Pro） |
| 按设备数分档 | 1 / 3 / 5 台 Mac |
| 应用内 License 面板 | 设置 / 菜单：试用 · 激活 · 停用 · 续期 |

公开话术可直接借用 Surge 逻辑：

> Luma Bar 使用了与 Mac App Store 不兼容的系统能力（辅助功能、跨应用上下文、本地会话监测等），因此完整版仅通过官网分发。

## 2. 授权模型（照抄 Surge 骨架）

### 2.1 一句话
**首次购买 = 永久许可（当前大版本能力）+ 12 个月维护更新订阅。**  
订阅过期后：可**无限期使用过期前最后一版**；要继续收新功能，需续订维护期。

### 2.2 建议定价（极致亲民：低首购、低续费）

Surge 结构保留，但 **首购直接用「一杯奶茶～一顿简餐」价**，降低决策门槛：

**首次购买（含 12 个月维护更新）**

| 授权设备数 | 价格（建议） | 心智 |
|---|---|---|
| 1 台 | **¥28** | 冲动下单 |
| 3 台 | **¥45** | 双机 / 家里两台 |
| 5 台 | **¥68** | 小团队仍便宜 |

**维护更新续费（12 个月）**

| 授权设备数 | 价格（建议） |
|---|---|
| 1 台 | **¥18** |
| 3 台 | **¥28** |
| 5 台 | **¥45** |

说明：
- **先让人买得起**：首购 ¥28 起，试用转付费阻力最小。
- 续费再低一档，减少「过期就不续」；靠用户量与口碑，不靠高客单。
- 大版本升级：维护期内免费；过期用户续维护即可跟上。
- 可选：**教育优惠 5 折**（1 台低至 ¥14）。
- AI 默认用户自备 Key；Cloud 额度另售，不绑进正价里抬贵。
- 若后期验证需求很强，再微调涨价（老用户可锁价 / 补差），比一上来定贵了没人买更安全。

### 2.3 试用
- **14 天全功能试用**（与 Surge Mac 对齐）。
- 试用结束：
  - **Free**：刘海、主题、宠物、基础音乐；
  - **Pro 能力关闭**：任务完成提醒、划词翻译、Agent 高级能力、系统控制等。
- 试用可要求邮箱激活（防滥用），但首版可先「本机一次试用」。

### 2.4 设备与转移
- 购买时选定 1 / 3 / 5 台。
- 允许用户在 App 内「停用此 Mac」再在新机器激活（Surge 同款体验）。
- 升级设备数：补差价，维护到期日对齐。

## 3. 功能分层（Surge 式：试用=完整，过期=收口）

| 能力 | Free / 试用过期 | Pro（授权有效） |
|---|---|---|
| 刘海灵动岛、主题、宠物 | ✅ | ✅ |
| 本地音乐基础播放 | ✅ | ✅ |
| Cursor / Codex / Cherry 完成提醒 | ❌ | ✅ |
| ⌥ 划词翻译 | ❌ | ✅ |
| Agent / Voice Whisper | 每日限次或关 | ✅ |
| 系统控制 / Shell Prompt | ❌ | ✅ |

**同一二进制，功能用 License 开关。** 不维护两套砍功能的商店包。

### 关于 AI 成本（Surge 没有的部分，必须补）
- **默认**：用户自备 DeepSeek / OpenAI Key（你卖软件授权，不卖 Token）。
- **可选增值（后期）**：Luma Cloud 额度订阅（走你的后端，防白嫖 Key）。
- **禁止**：把你的 API Key 打进公开 DMG。

## 4. 分发与工程（Surge 同款链路）

```
开发 → Developer ID 签名 → 苹果公证 (notary) → DMG
    → 官网 / GitHub Download Release
    → Sparkle 自动更新（仅维护期内或始终推送安全补丁策略自定）
    → 应用内 License 激活
```

### 必备动作
1. **Apple Developer Program** + **Developer ID Application** 证书  
2. `notarize` + `stapler` 后发 DMG（用户下载双击即可，少右键打开）  
3. 官网购买页（可先用 Lemon Squeezy / Paddle / Stripe Payment Link）  
4. License Server（可先极简）：
   - 发行 license key  
   - 激活 / 停用 / 设备数校验  
   - 返回：`plan`, `device_limit`, `maintenance_expires_at`, `signature`  
5. App 内「许可证」面板（菜单栏 → License…）  
6. 知识库 FAQ：为何不上架、试用规则、续费、设备转移（Surge KB 结构可直接仿）

### 更新策略（对标 FUS）
- 维护期内：Sparkle 推送功能更新。  
- 维护期外：仍可推**严重安全修复**（可选）；功能更新提示续费。  
- 过期用户永远能跑「过期前最后构建」（归档旧 build 供回滚，Surge 也提供回退思路）。

## 5. 官网信息架构（仿 nssurge.com）

1. **首页**：一句话价值 + 演示视频 + Download / Buy  
2. **功能页**：多 AI 并行提醒、划词、Agent（录屏 > 文案）

首页主张建议：

> Luma Bar — 为并行 AI 工作流而生的 Mac 刘海中枢。

## 7. 和 Surge 的差异（不要照搬错）

| | Surge | Luma Bar |
|---|---|---|
| 核心护城河 | 网络扩展 / 代理引擎 | 桌面工作流 + 本地上下文 |
| App Store | 技术上难以上架 | 同样难，**别为上架砍功能** |
| 持续成本 | 开发维护 | 开发维护 +（可选）模型额度 |
| 定价锚点 | 专业网络工具 ~$50 | **极致亲民：首购 ¥28 起**（结构同 Surge，先换量） |

## 8. 成功标准（第一季度）

- 公证 DMG，陌生 Mac「下载 → 打开 → 试用」无 Gatekeeper 劝退  
- 付费转化：试用用户 ≥ 8% 付费（亲民定价应力争高于高价工具；冷启动 ≥ 5% 亦可）  
- 支持负担可控：FAQ 覆盖权限与 License  
- 零「公开 Key 被刷爆」事故
