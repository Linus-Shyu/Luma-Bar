# Privacy Policy stub for luma bar

Live page: **https://linusshyu.dev/privacy/**

Paste that URL into App Store Connect → App Information → Privacy Policy URL.

## Summary

- **luma bar** is a macOS utility. Purchase is handled by Apple.
- On-device features (music UI, system metrics, notch UI) process data locally.
- Optional AI Agent features send prompts you type to the AI provider **you** configure (e.g. OpenAI / DeepSeek). We do not operate that server.
- Selection Translation is off until you turn it on and agree in a dialog. While it is on, text you copy twice in a row is sent to that same AI provider (DeepSeek, or OpenAI if you chose it) to be translated. Nothing is sent while it is off, and we do not keep a copy of your clipboard.
- Optional Cursor/Codex overlays read files only in folders **you** explicitly grant.
- Voice Whisper audio is processed on-device (or by Apple speech APIs) only when you start recording.
- We do not sell personal data. We do not use your content for third-party advertising.
