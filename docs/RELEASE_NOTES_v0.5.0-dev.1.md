# Luma Bar v0.5.0-dev.1 更新报告

**日期：** 2026-08-10  
**版本：** `0.5.0-dev.1`（内部预发）  
**Git tag：** `v0.5.0-dev.1`

---

## 摘要

本版主打两件事：**应用内多语言**，以及 **Aura 高度透明毛玻璃 + 可调浓淡**；并修掉桌面 Spaces 滑动时岛条偶发「黑块」的问题。大量界面文案已接入本地化目录。

---

## 1. 多语言

- 菜单新增 **Language**：跟随系统，或手动选择语言。
- 新增 / 完善本地化：简体中文、繁體中文、English、日本語、한국어、Français、Deutsch、Español、Português (Brasil)、Italiano、Русский。
- `Info.plist` 声明对应 `CFBundleLocalizations`；切换语言后菜单、Help、权限引导与岛内主文案会刷新。
- 修复 SPM 打包后 `zh-Hans` 等 lproj 大小写不一致导致读不到翻译的问题。

---

## 2. Aura 主题

- 底子改回**系统毛玻璃**（非实心白/黑底），避免最大档看不清浅色字。
- **Theme → Aura ▸** 增加 Opacity 滑杆：偏左更透，偏右略加霜；整体偏高透明，最高档也不会糊成实底。
- 卡片 / 控件表面跟随同一透明度偏好，略淡于主面板。

---

## 3. Spaces 滑动

- 岛窗口改用 `.moveToActiveSpace` 等行为，跟随当前桌面切换动画。
- 普通桌面滑动时**不再刷实色遮罩**，消除菜单栏附近的黑块感。
- 保持 notch 层级，避免岛条掉到菜单栏/摄像头下面。

---

## 4. 建议自测

1. Language 切到日语 / 繁中等：菜单、About、Help、岛内状态文案是否更新。
2. Theme → Aura：滑杆从左到右，毛玻璃由很透到略霜，文字仍可读。
3. 三指 / 触控板切换 Spaces：岛条应跟桌面一起动，顶部不应闪黑块。
4. 其它主题（Void / Horizon 等）外观与交互不受 Aura 改动影响。
